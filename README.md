A lightweight, mobile-optimized web application built with vanilla web technologies, featuring immersive ambient audio, interactive celestial canvas effects, and a secure dynamic link manager.

---

## 🌟 Features

* **Dynamic Celestial Canvas:** Real-time particle background and touch-activated firework effects.
* **Web Audio API Integration:** Ambient chime generation without relying on external media files.
* **Custom Link Management:** Securely add, view, and delete custom navigation shortcuts via browser `localStorage`.
* **Theme Switcher:** Seamlessly toggle between multiple cosmic color palettes using dynamic CSS variables.
* **Real-time Clock & Calendar:** Localized timekeeping and calendar tracking for smooth user experience.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox, Backdrop Filter, CSS Variables), JavaScript (ES6+)
* **Storage:** Browser `localStorage` for persistent custom links
* **Hosting:** GitHub Pages
