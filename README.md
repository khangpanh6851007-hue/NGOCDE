## 📜 Giới thiệu
Trang web **Cung Trời Hóa Lạc** là không gian giao diện trực tuyến được thiết kế gọn nhẹ, mượt mà, chạy trực tiếp trên nền tảng GitHub Pages. Dự án tích hợp hệ thống thời gian tự động giúp đồng bộ hóa thời gian và lịch âm dương/dương lịch ngay tại giao diện chính.

## ✨ Tính năng nổi bật
* **⏰ Đồng hồ Cung Trời tự động:** Cập nhật giờ, phút, giây liên tục theo thời gian thực (Real-time).
* **📅 Lịch tự động:** Hiển thị chính xác ngày, tháng, năm và thứ trong tuần tự động cập nhật mỗi ngày.
* **👑 Kết nối Ngọc Đế:** Điều hướng nhanh chóng đến điện của Ngọc Đế.
* **🏛️ Kết nối Thiên Đình:** Truy cập hệ thống trung tâm Thiên Đình một cách dễ dàng.
